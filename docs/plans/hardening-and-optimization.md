## 7. Already done well (don't redo)

- Origin check fails closed and is used on chat, session, contact and conversions. The IP comes from `cf-connecting-ip` only.
- Chat:
  - Fail-closed: requires the secret, 3 limiters and an HMAC session (IP-bound, 30 min, constant-time compare). Turnstile checks action and hostname.
  - Inputs and outputs: 500-char questions, 400 output tokens, a 16 KB streamed body cap. Client history is ignored.
  - Defenses: NFKC and invisible-character stripping, a canary, an allowlisted-URL output guard. Logs record event names only.
- `/stats` fails closed with a constant-time compare. Reaction keys are bounded by the published-slug allowlist.
- All secrets in `.env.schema` are `@sensitive`. `.env*` is gitignored. lefthook runs `varlock scan`.
- `ci-cd` and CodeQL pin SHAs, use `persist-credentials: false`, harden-runner and `permissions: contents: read`. CI uses `pull_request` (not `_target`) and passes no secrets to CI.
- `bun.lock` with `--frozen-lockfile`. No `trustedDependencies`, so install scripts stay blocked.
- Every page except `/ask`, `/stats` and `/api/*` is prerendered. `/_astro/*` is immutable. APIs are `no-store`. `sw.js` only unregisters itself. The home page ships ~16 KB of JS.
- Skip link, global `:focus-visible`, mobile menu focus trap with Escape, form `aria-invalid`/`role=alert`, and `prefers-reduced-motion` support are all in place.
